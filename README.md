# EventHive

### Event Booking Platform

EventHive is a web-based platform designed to make event booking simpler, faster, and more organized.

Instead of handling event enquiries through calls and messages, clients can browse event packages, submit booking requirements, and receive booking-status updates online.

---

## Why EventHive?

Event-management businesses often manage client enquiries through calls, messages, and manual records. This can make it difficult to track package selections, event dates, client details, and booking progress.

EventHive provides a simple digital solution where clients can explore event packages, submit their requirements, and send booking enquiries online.

---

## Key Features

### For Clients

- Browse event categories and packages
- View package descriptions and included services
- Select an event package
- Submit a booking enquiry
- Enter event date, location, contact details, and attendee estimate
- Receive booking acknowledgement
- Check booking-status updates

### For Admin

- Secure administrator login
- Add, update, and remove event packages
- Manage package details and descriptions
- View client booking enquiries
- Review event requirements
- Update booking status
- Maintain organized booking records

---

## How It Works

```text
Client Visits EventHive
      ↓
Browse Event Packages
      ↓
Select a Package
      ↓
Enter Event Details
      ↓
Submit Booking Enquiry
      ↓
Booking Record Created
      ↓
Admin Reviews and Updates Status
```

---

## Main Modules

| Module | Purpose |
| --- | --- |
| Client and Enquiry Module | Package browsing and booking enquiry submission |
| Event Package Module | Maintains package details and service information |
| Booking Management Module | Stores client, event, and booking details |
| Admin Module | Manages packages and booking enquiries |
| Authentication Module | Protects administrator access |
| Validation and Status Module | Validates booking details and updates status |
